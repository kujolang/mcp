# Checklist Loop Workflow

Use this sequence for one loop:

1. Select the first unchecked actionable checklist item.
2. Create a concise todo list for that one item.
3. Inspect only relevant files.
4. Add or update tests first when practical.
5. Implement the item fully.
6. Run targeted validations and required family-level checks.
7. Update docs only when directly relevant.
8. Mark the item complete and append a Work Log record.
9. Commit exactly once for the loop with item ID in the message.
