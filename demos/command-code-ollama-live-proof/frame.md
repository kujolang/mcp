# Visual direction

The actual Command Code terminal is the focal element and fills nearly the
entire frame. Thin technical rails establish BB Kujo provenance without
recreating or obscuring the host UI. Command Code purple marks only live state
and the verified receipt. The title card is brief; the proof remains on screen
long enough to read.

Use the embedded Departure Mono asset throughout. Avoid rounded cards, glass,
gradient text, fake terminal chrome, decorative diagrams, or any visual that
could be mistaken for host output.
