# Visual direction

The focal element is the live evidence panel. Left/top edge anchors carry the
scene and run labels; a persistent bottom rail shows the portable execution
path. The BB Kujo workflow artwork sits behind the content as faint structural
geometry. Hairline borders and short white signal sweeps replace shadows.

Use Departure Mono for technical labels, commands, identifiers, and large
display copy. Use Arial only for short explanatory sentences. No gradients,
rounded card stacks, glass effects, drop shadows, floating centered layouts,
fake application chrome, or decorative connectors without real endpoints.
